# Homepage artwork

At the user's request, the generated raster collage was removed and replaced
with original inline SVG in `features/home/components/culture-artwork.tsx`.
The SVG uses semantic theme colors for a geometric film strip, television,
record and controller. It represents media formats, not existing catalog works.
It has an accessible image label and scales with its viewBox.

Interface icons come from `@tabler/icons-react` (MIT). Theme actions use sun,
moon and desktop icons with accessible button names and pressed states.

Fonts are self-hosted in `public/fonts/`. Fraunces and DM Sans came from their
Google Fonts repositories, with the supplied OFL licenses retained. The WOFF2
files are Latin subsets; the variable weights cover the homepage's used weights.
