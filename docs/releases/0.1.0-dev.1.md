# 0.1.0-dev.1

Development candidate notes; no public release is recorded.

## Changes

Introduce shared build version/revision metadata, release-bundle preparation and
manual loading, and optional administrator update checks. GitHub release
subscriptions provide announcements when an authorized release is published.

## Upgrade

The implementation rehearsal uses source revision `9cc808a` with synthetic data.
There is no preceding published stable bundle. Stop all writers and retain a
coordinated database/artwork/key backup and matching previous image set. Follow
load-release (or source build), prepare, explicit migrate, then start. No automatic
upgrade runs. Recheck instance overrides and provider prerequisites separately.

## Migrations

This feature adds no schema migration. The candidate retains the existing final
`20261119165037_AddProfileAvatars` schema. The operator must still explicitly run
migrate to bind startup acceptance to the complete new image set.

## Recovery

Keep previous artifacts and the independent current erasure journal. A failed
migration leaves writers stopped. Use a reviewed forward fix or an isolated
matching-version restore with erasure replay; do not run old code blindly against
a changed schema.

## Known issues

Only single-host Linux amd64 is supported by the reference packaging. Update
checks default to disabled and require GitHub connectivity when enabled. Provider
clearance, final image-bound source delivery and the remaining STATUS release
gates are independent blockers. This development candidate is not public-release
clearance, and no hosted GitHub Actions execution is claimed.
