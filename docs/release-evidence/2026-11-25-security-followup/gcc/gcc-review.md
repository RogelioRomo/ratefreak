# GCC native caller review, 2026-11-25

This is scoped caller evidence for six GCC findings. It does not grant release clearance or change the advisory ledger. `gcc-assessments.json` contains each condition, proposed disposition and remaining limits. The current API, web and tools image digests are bound in that file and in each image probe; a subsequent build must be rebound by native-payload hashes.

The strongest exclusions are CVE-2026-95619 (actual compiled `posix_memalign` branch does not perform the affected round-up) and CVE-2026-115456 (no affected GCC floating `from_chars` caller in the current image ELF closure, with exact application source distinguishing integral/custom parsers). The vulnerable GCC library package may remain installed: these conclusions concern compiled behavior and callers, not package remediation.

|---|---|---|
| CVE-2026-102010 | No GNU pbds headers/types or symbols in reviewed application source/build closure. Ordinary STL priority queues do not invoke the affected GNU extension heap. | Keep global finding open until OS-consumer header-instantiation closure is established or those consumers rebuilt with fixed headers. |
| CVE-2026-114690 | No GNU parallel-mode define, explicit namespace, or parallel algorithm/search include in application source/build closure. | Inlined code cannot be cleared from symbol absence alone; OS consumers remain unproven. |

Source search includes 36 exact archives and 41,666 C/C++/header/build files: Skia157, Sharp/libvips closure, Node24.22.3, current .NET runtime source revision and ICU74/76. `source-search.json` retains archive/file hashes and matching lines. Search includes test/tool sources; match classification was reviewed separately rather than treating the script's heuristic `test_or_example` flag as authoritative. Zero source matches is evidence for these materials, not a promise that every installed binary was rebuilt from this exact source set.

`probe-full.py` walks `/usr`, `/app`, `/bin`, `/sbin`, `/lib`, `/lib64` in disposable containers with no network, read-only filesystem and dropped capabilities. It inspects ELF symbol and dynamic tables, including regular symbols if available. It reports 1,632/1,433/1,650 ELF records for API/web/tools; `/usr` merge aliases mean these counts include duplicate paths to identical bytes. `caller-summary.json` summarizes actual imported versus defined parser APIs and stream importers. Dynamic symbol absence does not exclude inline templates; this limitation is the reason three header advisories remain globally open.

`acquisition.json` records exact primary upstream fix/header URLs and hashes; `consumer-acquisition.json` records exact Node/.NET source downloads. `libstdcpp-binding.json` binds the extracted current library hashes to each image and the retained aligned-new disassembly. `selected-source-files*.json` binds extracted caller source snippets to archives. `proof-manifest.json` records proof-file hashes and 36 reverified source archives. Regenerate that manifest only after final edits with `python .../glibc-callers/finalize_assessment.py`.

No product code, persistent service or historical evidence was changed. No compiler rebuild attestation is asserted.
