# Updated exact-image source delivery review

This source set describes the nonofficial local security-update proof images
and installation archive identified by coverage.json and SOURCE_REVISION. It
does not finalize a public/stable release, approve provider use or waive residual
OS vulnerabilities. All complete source and notice materials must accompany any
authorized matching binary distribution; filenames below refer to this bundle.

The nine changed OS source package/version pairs are supplied in
os-source-updates.tar, with authenticated signed APT indexes, complete descriptor
inputs and verified archive hashes. Other exact OS source pairs are supplied in
ratefreak-candidate-os-sources.tar. Its original image IDs are historical; the
current os-image-bindings.json and coverage.json establish current applicability.
No OS source exception is inferred from the application license. Each archive
explains restoring original filenames before dpkg-source extraction/build.

The .NET 10.0.15 image/license/composite and exact VMR commit license/notice texts
were compared byte-for-byte with previously reviewed grants. Their complete
source texts and source manifest are included; runtime-input-review.md records
the exact commit and pins. The changed framework versions receive fresh source
exception records conditional on those verified notices, not relabeled old IDs.
Node 24.22.3's complete composite license is byte-identical to the prior reviewed
file and accompanies its new binary. Preserve every embedded copyright/license
and disclaimer. No additional source-publication condition was identified in
those matched grants; these conclusions do not cover unrelated OS libraries.

The application package metadata and complete collected license/notice manifests
are byte-identical to the prior reviewed candidate for each image. Individual
package conclusions in prior-component-review.md therefore remain applicable to
those exact unmodified packages; current coverage maps their actual payloads.
Preserve complete MIT, ISC, BSD, 0BSD, PostgreSQL, Apache, CC-BY, Blue Oak and CC0
texts/attributions and all separately bundled notices. The optional Next MPL OG
implementation/WASM remains absent from every distributed layer; existing MIT
wrapper imports do not supply that absent implementation. This is not permission
to introduce an OG feature without a new source/notice review.

The sharp-libvips native sidecar is freshly bound to the updated web image and
validates the same complete 406-input source/build profile and binary hash.
Its LGPL/GPL texts and replacement instructions remain required. Neither its
earlier offline rebuild nor addon binary reproduction was repeated. The sharp
addon source/header materials and original Node-addon-api collaborator notice
are retained separately, with the existing explicit minimum-header-resolution
limitation. Skia's complete supplemental FTL/IJG/other notices and portable notice
archive accompany the unchanged pinned native payloads. Font hashes and original
OFL notices remain unchanged in the installation source and web public directory;
their original download/subsetting history is not newly reconstructed.

npm/Corepack/Yarn, gosu and PostgreSQL server/entrypoint binaries are absent from
all updated final layers. Old copied-runtime source decisions do not silently
carry over to different components. The PostgreSQL client and libraries have
explicit OS source mappings. Installation source retains the new Dockerfiles,
repository signing key and maintenance/build instructions. Publication, residual
security review and final stable source/version qualification remain separate.
