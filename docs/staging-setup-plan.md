# Staging setup plan — superseded

The 2026-11-10 draft assumed a project-owned deployment. The user clarified that
RateFreak will be released as an open-source app for others to self-host.

Use the [self-hosted release plan](self-hosted-release-plan.md) and
[ADR 0020](adr/0020-self-hosted-open-source-distribution.md). A temporary staging
installation can verify the reference package, but selecting a central hosting
provider is not the next project task. Existing account, storage and staff
runbooks remain applicable to each installation.
