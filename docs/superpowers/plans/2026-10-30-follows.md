> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Deliver directed follows, followed by IGDB in a separate slice.
**Architecture:** Domain relationship, application contract, EF service and Minimal API endpoints.
**Tech Stack:** Existing .NET 10, EF/Npgsql, xUnit, Testcontainers; no new dependencies.
**Spec:** docs/superpowers/specs/2026-10-30-follows-design.md

## Global Constraints

Use authenticated actor only; CSRF on writes; no private account data; no-store;
public graph confers no extra access. Repeat writes return 204 without changing time.

## Review Focus

Concurrent repeats must produce one row; missing/deleted accounts must not cause 500;
ties must paginate stably; projections must exclude email/security fields; deletion
of either endpoint must remove only related edges.
