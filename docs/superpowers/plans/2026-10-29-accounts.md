> For agentic workers: use superpowers:executing-plans for inline execution.

Architecture: Application account records/interface/validation, Infrastructure
Identity user/store/service and EF migration, Api cookie/CSRF/rate-limit endpoints.
Tech: .NET 10, ASP.NET Identity/EF 10.0.2, PostgreSQL 17, xUnit/Testcontainers.
Spec: ../specs/2026-10-29-accounts-design.md and ../../adr/0004-local-accounts.md.

## Constraints and review focus

No business entities/frontend/provider work. No plaintext passwords, secrets in
responses, startup migrations or anonymous /users/me. Replayed cookies after logout
must fail. Forged login/register/logout requests must fail. Concurrent case variants
must not create duplicate emails/handles. Return 401/403 JSON rather than redirects.
Secure cookies and durable keys outside Development; bounded input and rate limits.
